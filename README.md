Sistema Web para la Administración de Conjuntos Habitacionales

Aplicación web gratuita y de código abierto que centraliza la gestión financiera, la comunicación oficial y el seguimiento de mantenimiento de conjuntos habitacionales (cotos, fraccionamientos y condominios) pequeños y medianos de la Zona Metropolitana de Guadalajara.

Proyecto de titulación (modalidad Reporte de Proyecto) de Ingeniería en Tecnología de Software, CETI Plantel Colomos.

Autores: Gómez Iñiguez Paloma Alejandra · Mariscal González Edson Wladimir
Asesor: Dr. Omar Alejandro Chávez Campos
Demo: https://conjuntos-habitacionales.vercel.app

Estado: prototipo funcional validado en un piloto simulado.
